# Index of Figures and Result Tables

This document indexes all visualization figures (`results/figures/`) and formatted result tables (`results/tables/`) generated by the Sinhala-English AI Assistant Evaluation Framework.

---

## 1. Visual Figures (`results/figures/`)

### Figure 1: `pass_rate_by_language.png`
- **Displays**: Overall pass rate percentage ($0\% - 100\%$) across the four language modalities: English, Sinhala, Singlish, and Sinhala-English Code-mixed.
- **Source Data**: [`results/tables/performance_by_language.csv`](file:///d:/Internship%20Tasks/Task%20-%202026.09.22/Sinhala-English-AI-Assistant/results/tables/performance_by_language.csv)
- **Primary Axis**: Pass Rate (%) on 0–100 scale.

### Figure 2: `average_score_by_language.png`
- **Displays**: Mean overall evaluation score (out of 14 maximum points) grouped by language type (English, Sinhala, Singlish, Code-mixed).
- **Source Data**: [`results/tables/performance_by_language.csv`](file:///d:/Internship%20Tasks/Task%20-%202026.09.22/Sinhala-English-AI-Assistant/results/tables/performance_by_language.csv)
- **Primary Axis**: Average Overall Score (0 to 14 scale).

### Figure 3: `pass_rate_by_difficulty.png`
- **Displays**: Pass rate percentage ($0\% - 100\%$) categorized by prompt difficulty level: Easy, Medium, and Hard.
- **Source Data**: [`results/tables/performance_by_difficulty.csv`](file:///d:/Internship%20Tasks/Task%20-%202026.09.22/Sinhala-English-AI-Assistant/results/tables/performance_by_difficulty.csv)
- **Primary Axis**: Pass Rate (%) on 0–100 scale.

### Figure 4: `average_dimension_scores.png`
- **Displays**: Mean evaluation score (0 to 2 points) across each of the seven human evaluation dimensions (Policy Correctness, Intent Understanding, Relevance, Completeness, Language Appropriateness, Safety/Privacy, Hallucination Control).
- **Source Data**: [`results/tables/dimension_scores.csv`](file:///d:/Internship%20Tasks/Task%20-%202026.09.22/Sinhala-English-AI-Assistant/results/tables/dimension_scores.csv)
- **Primary Axis**: Average Score (0 to 2 scale).

### Figure 5: `failure_type_frequency.png`
- **Displays**: Counts of recorded failure types across all evaluated test cases, ordered from highest frequency to lowest frequency.
- **Source Data**: [`results/tables/failure_type_frequency.csv`](file:///d:/Internship%20Tasks/Task%20-%202026.09.22/Sinhala-English-AI-Assistant/results/tables/failure_type_frequency.csv)
- **Primary Axis**: Frequency Count.

### Figure 6: `pass_rate_by_category.png`
- **Displays**: Pass rate percentage ($0\% - 100\%$) across all represented e-commerce business inquiry categories (Categories A through M).
- **Source Data**: [`results/tables/performance_by_category.csv`](file:///d:/Internship%20Tasks/Task%20-%202026.09.22/Sinhala-English-AI-Assistant/results/tables/performance_by_category.csv)
- **Primary Axis**: Pass Rate (%) on 0–100 scale.

### Figure 7: `dimension_scores_by_language.png`
- **Displays**: Grouped comparison of mean scores (0 to 2 scale) for each of the seven evaluation dimensions split across the four language modalities.
- **Source Data**: [`results/tables/dimension_scores_by_language.csv`](file:///d:/Internship%20Tasks/Task%20-%202026.09.22/Sinhala-English-AI-Assistant/results/tables/dimension_scores_by_language.csv)
- **Primary Axis**: Average Dimension Score (0 to 2 scale).

### Figure 8: `latency_by_language.png`
- **Displays**: Operational API latency in seconds averaged by language modality.
- **Source Data**: [`data/processed/final_llm_responses.csv`](file:///d:/Internship%20Tasks/Task%20-%202026.09.22/Sinhala-English-AI-Assistant/data/processed/final_llm_responses.csv)
